# paper 文献检索与阅读策略

适用范围：连接了 paper MCP（工具名前缀 `mcp__paper__`）的会话。本地文献库已全量向量化时，多数常用文献的全文可直接读取。

## 传输与身份规则

- 本地 stdio 保持 `paper mcp` 与全部 19 个工具。HTTP 传输（`paper mcp --transport http`）隐藏并拒绝 `ingest_local_file` 与 `ingest_local_files`（17 个工具）；服务器本地 PDF 只能通过 stdio 投递。
- 公开版没有登录与角色体系，stdio 与 HTTP 的工具语义一致；HTTP 传输的安全边界是回环监听，不要把它当作有访问控制的入口。

## 检索顺序是先本地库、后外部源

本地库命中的论文可以直接读全文与结构化总结；外部检索只用于找库外的新论文。按以下顺序：

1. **`search_library`**（关键词检索）。`q` 参数先匹配元数据（title / dir_name / first_author / keyword / abstract / authors / doi），多词逐词 AND（词不必相邻连续）；零命中时自动回退全文检索（FTS5），返回的 `matched_by` 字段标记命中来源（`metadata` 或 `fulltext`）。`fulltext` 参数强制全文检索（FTS5 隐式 AND，宜 2-4 个实词；超过 3 词 AND 落空时自动降级 OR + bm25）；`q` 与 `fulltext` 同时提供时是 AND 语义，且此时禁用回退。
2. **`semantic_search`**（语义检索，向量两阶段）。概念、主题、方法描述类的自然语言查询优先用它，描述性语句比关键词更有效。跨库结果已按论文去重，每篇论文返回一个最相关片段（含 `paper_id`、`score`、`text`、`char_start`、`char_end`）。加 `paper_id` 可在单篇内定位特定概念/说法：单篇模式保留多片段、不做相关性阈值过滤，低于跨库阈值的片段带 `low_confidence: true`。需要读取上下文时调用 `read_fulltext(paper_id, offset=char_start, limit=char_end-char_start)`；`chunk_index` 是片段编号，不是 `read_fulltext` 的字符偏移。
3. **`search_papers`**（外部四源：arxiv / openalex / semantic_scholar / sciverse，不写库）。小众术语、方法名、产品名优先 `semantic_scholar`；openalex 与 sciverse 对小众术语常返回无关结果，某一源结果差时换源重试，不要直接下「查不到」的结论。query 直接给 DOI（裸 DOI 或 doi.org URL）时 semantic_scholar/openalex 自动走精确解析。结果条目带 `in_library: [paper_id, ...]` 时表示本地库已收录该 DOI，直接转 `get_summary` / `read_fulltext` 阅读，不必再逐条 `get_paper_by_doi` 核对。
4. 外部找到且不在库的目标论文可用 `ingest_by_url` 入库（返回 `task_id`，用 `get_task` 轮询到 ok 后再读取）。

## 遇到不认识的缩写或专名，先检索再判断领域

- 缩写与论文产品名不要凭记忆猜测所属领域。先用缩写本身检索 `search_library`，再用可能的全称展开检索 `semantic_search`，用命中论文的标题、作者、期刊来判断它的领域。
- 上下文没有领域线索、且本地库两种检索都无命中时，向用户确认所指，不要按猜测方向展开外部检索。

## 检索结果已在上下文中时，以返回值为准

- 归属信息以工具返回的元数据为准：作者、期刊、年份、DOI 都用返回值，不要用记忆中的印象覆盖。检索结果第一条的作者列表里已经写明通讯作者时，按返回值归属。
- `search_library` 返回 `count=0` 不等于库里没有：换 `semantic_search` 再查一次，两种检索都为零才说明库内无此内容。
- 读论文先 `get_summary`（结构化中文总结），再按需 `read_fulltext` 分页读取（`offset` / `limit` 为字符偏移，单次上限 50000；返回的 `total` 与 `has_more` 指示剩余内容；`toc` 章节目录只在 `offset=0` 的首页返回，翻页不再重复携带）。
- `read_translation(paper_id)` 可读中文翻译全文（分页，与 `read_fulltext` 同构）；读论文细节需要中文时用它而不是自己翻译 `read_fulltext` 的英文片段。
- `get_paper` 返回 `abstract` / `keyword` / `authors`，可用于核对一篇论文的元数据是否空缺。

## 方法归属断言必须先过全文计数

「论文 X 使用方法 Y」类断言（用了什么方法、什么任务、什么分析）必须先核验再写入：

- X 在本地库：用 `search_fulltext(paper_id=X, query="Y")` 对方法名计数（字面匹配，大小写不敏感），把命中数写进交付物；计数为 0 即否决该断言。历史实例中出现过「凭印象归属的方法在全文出现 0 次，改判后实际使用的是另一种方法」的情况。
- 计数 ≥ 1 只证明方法名出现，用途与方式仍需 `read_fulltext` 读到相应段落才能下断言。
- 方法名有变体时两种写法各查一次（如缩写与全称）；查数字与单位时注意空格和连字符的写法差异。
- X 不在本地库：先 `ingest_by_url` 入库再按上述核验，或者把断言降级并显式写「未读全文、未核验」，不得写成确定结论。

## 事实断言按证据分级标注，verified 只给读到原文支撑段落的条目

- 交付物中每条文献断言标注证据等级：[原文]（读到支撑该条目的原文段落，可给引句与位置）、[摘要]（只核过摘要或元数据）、[线索]（间接证据：他人参考文献条目、转述、讲座所述）。只有 [原文] 级可以标 verified；只看过摘要或截断片段的条目最高标 [摘要]，禁止标 verified。
- 任务描述是图式补全的高发位置：不要用领域内高概率的任务图式填补没读到的任务细节；未读到任务结构段落时，任务描述一律标 [线索] 或 [摘要]。历史实例中出现过「任务被凭图式写成另一种范式，精读后实为不同操纵」的情况。
- 同一轮输出里，查证过的断言与未查证的断言不得无标识地混排——分级标注就是为此存在。
- 承担方法选型或科学问题定义的论据论文，进入结论前先过 [原文] 级精读：每项附原文关键句与位置、所有数字出自原文、缺失维度写「原文未报告」。
- 修正执行后对交付物 grep 一次，确认声称已写入的修改确实存在。

## 引用字段与任务书背景不得凭记忆写入

- 引用字段（作者、期刊、卷期、DOI）以工具返回为准；记忆给出的 DOI 与卷期先用 `search_papers`（DOI 解析）或 `get_paper_by_doi` 反查确认再写，未经解析的记忆 DOI 直接丢弃。历史实例中出现过「凭记忆写下的 DOI 解析后属于完全无关的论文；凭记忆写下的卷期在外部数据库全库无记录」的情况。
- 向子代理派发任务时，背景段的每条事实标来源（哪份报告第几节、出自对话记忆、或出自用户）；对话记忆来源的写法是「待查证假设」，不得写成「已知」事实。主对话对自己适用同一条规则——凭记忆写下「已知用它做分析的经典应用包括……」，就是未核实的候选变成断言进入下游的开端。

## 派发文献调研子代理时，按此任务书模板起草

模板的存在理由：历史会话实录中，方法归属错误大多源自任务书背景段把记忆写成「已知事实」。派发时填好花括号占位符后整段复制为子代理 prompt。三条填法纪律：

- 背景段每条事实末尾必须跟来源标注：`[报告 路径#节号]`、`[对话记忆→待查证假设]` 或 `[用户]`；没有可靠来源的条目直接删掉，不要降格成模糊表述保留。
- `[对话记忆→待查证假设]` 条目的措辞必须以待查证开头，禁止写成「已知」。
- 模板里写给子代理的每条规则，主对话自己写综述与回复时同样执行。

```
你是文献调研子代理，任务：{一句话目标，写明产出给谁用、回答什么问题}。

## 背景（供定位，不必复述；每条末尾标来源）
- {事实一 [报告 路径#节号]}
- {事实二 [对话记忆→待查证假设]}
- {用户给定的约束 [用户]}

## 必须逐篇核实的锚点（逐个查证，不得跳过）
1. {文献引用 [来源]}——查证：存在性；元数据（作者/期刊/年份/DOI 以工具返回为准）；是否真用了所声称的方法——本地库条目必须 search_fulltext 计数并把数字写进交付物，计数为 0 即否决。

## 检索要求
- 顺序：先本地库（search_library，零命中再 semantic_search，两者都零才算库内无此内容），后外部源（search_papers，某一源结果差就换源重试）。{默认禁止写库类工具；如允许入库，在此注明可用 ingest_by_url}
- 引用字段（作者、期刊、卷期、DOI）一律以工具返回为准，禁止凭记忆写引用；记忆给出的 DOI 未经 search_papers 的 DOI 解析或 get_paper_by_doi 反查确认，一律丢弃不写。
- 任务描述与方法归属必须读到原文段落才可下断言（read_fulltext）；未读到的维度显式写「未读全文，未核验」。

## 交付格式（严格按此结构）
- 每篇论文：完整引用 / 任务类型 / 用了什么方法（附计数或引句）/ 主要结果 / 证据等级。
- 证据等级定义：[原文] = 读到支撑该条目的原文段落并给引句与位置；[摘要] = 只核过摘要或元数据；[线索] = 间接证据（他人参考文献条目、转述）。只有 [原文] 级可以标 verified，禁止给 [摘要] 或 [线索] 条目标 verified。
- 查证不到的条目如实写「未找到」，不得断言「绝对不存在」。
```
